Dev notes
  • Grid: 3 cols mobile → 4 (md) → 5 (xl) → 6 (2xl), gap 12px→20px; left-aligned, never stretched to fill on short collections.
  • Card = cover (rounded-2xl, aspect 2/3) + 8px + title (2-line clamp, 14px semibold) + 4px + subtitle (12px, textDim) + 6px + type pill (10px, surface bg). Never text-over-image.
  • Stats: 2+ useful metrics → paired StatCards top-right; exactly 1 → inline compact text (no lone card); 0 → header shows only title + chips.
  • Chips always show counts, including "0" for an empty type — never hidden.
  • "Par série"/"Par tome" is a real view toggle on the same grid, not a separate screen.

Dev notes
  • Single contextual surface: clicking a tome replaces the drawer's content — never opens a second block lower in the page, never two drawers at once.
  • Desktop: non-modal drawer (top-16 → bottom, w-420px, right-aligned) — no overlay, so clicking another tome tile switches content directly instead of first closing.
